왜 만들었나

브랜딩은 비싸고, 오래 걸리고, 일관성을 잃기 쉽습니다.

1인 개발자와 초기 스타트업은 짧은 시간 안에 정체성을 세워야 하지만, 로고·컬러·타이포·메시지를 일관되게 설계하려면 전문 역량과 비용이 듭니다. BrandKit은 이 과정을 키워드 입력 하나로 압축합니다.

설계에 수일~수주 소요 디자이너·에이전시 비용 디자인 툴의 높은 학습 난도 템플릿은 고유성 부족
사용자

1인 개발자 · 인디 메이커

디자이너 없이 빠르게 제품의 첫인상을 세워야 하는 사람.

초기 스타트업

MVP 단계에서 일관된 브랜드 톤을 저비용으로 잡고 싶은 팀.

사이드 프로젝트 · 동아리

짧은 기간 안에 그럴듯한 브랜드 외관이 필요한 프로젝트.
핵심 기능

브랜드 전략

브랜드명 후보와 선정 이유, 한·영 슬로건, 에센스, 코어 밸류, 톤앤매너, 비주얼 방향성까지 정의합니다.

컬러 시스템

Primary·Secondary·Accent와 Neutral, Semantic 컬러를 자동 구성합니다.

타이포그래피

폰트 페어링을 선정하고 Display부터 Caption까지 타입 스케일·굵기 시스템을 잡습니다.

UI 컴포넌트

버튼·인풋·배지·태그·카드의 색상·크기·상태별 스타일을 자동 설계합니다.

스페이싱 시스템

간격 스케일, Border Radius 규칙, 그리드를 일관된 토큰으로 구성합니다.

로고 심볼

Gemini Image API로 브랜드 성격에 맞는 로고 심볼을 생성하고 저장합니다.
동작 방식
INPUT

키워드 입력

브랜드 키워드(필수)와 업종·브랜드명(선택)을 입력합니다.

→
AI

Gemini 처리

전략 → 컬러 → 타이포 → 컴포넌트를 스트리밍 생성하고 로고를 만듭니다.

→
OUTPUT

가이드북 출력

인터랙티브 가이드북으로 시각화하고 SVG·PNG로 내보냅니다.

사용자가 입력한 키워드는 AI 처리 후 서버에 저장되지 않으며, 생성된 데이터는 브라우저 세션 내에서만 유지됩니다.

완료 조건
  • ✓ 키워드 입력만으로 브랜드 전략·컬러·타이포·컴포넌트가 자동 생성된다
  • ✓ 생성된 디자인 시스템을 인터랙티브 가이드북으로 확인할 수 있다
  • ✓ 로고 심볼이 브랜드 성격에 맞게 이미지로 생성된다
  • ✓ 결과물을 SVG·PNG로 즉시 내보낼 수 있다
  • ✓ 전체 과정이 3분 이내에 완료된다
