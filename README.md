# Brandkit

> 브랜드 키워드를 입력하면 로고, 컬러, 톤앤매너가 통합된 인터랙티브 디자인 시스템 가이드북을 자동 생성해주는 서비스

---

## 소개

새 프로젝트를 시작할 때마다 브랜드 아이덴티티를 정하는 과정은 생각보다 어렵고 시간이 많이 걸립니다.
프로젝트명, 로고, 컬러, 톤앤매너를 일관성 있게 구축하려면 전문 디자이너의 도움이 필요하지만,
1인 개발자나 초기 스타트업은 그럴 여유가 없습니다.

**Brandkit**은 브랜드 키워드만 입력하면 AI가 브랜드 성향을 분석하고,
바로 활용 가능한 수준의 디자인 시스템 가이드북을 자동으로 생성해드립니다.

---

## 핵심 기능

### 1. 브랜드 아이덴티티 자동 생성
브랜드 키워드를 입력하면 AI가 브랜드명, 슬로건, 컬러 시스템, 폰트, 톤앤매너를 자동으로 분석하고 생성합니다.

### 2. 인터랙티브 디자인 가이드북
생성된 결과를 컬러 시스템, 타이포그래피, 여백 시스템, UI 컴포넌트로 구성된 완성도 높은 가이드북으로 제공합니다.

### 3. AI 자가 학습 시스템
매 생성 결과를 AI가 자동 평가하고 프롬프트를 누적 개선하여 사용할수록 더 정교한 결과를 제공합니다.

---

## 사용 방법

1. 브랜드 키워드 입력 (예: 친환경, 미니멀, 신뢰감)
2. 업종 선택 (선택사항)
3. 브랜드명 입력 또는 AI 추천 (선택사항)
4. 생성하기 클릭
5. 브랜드 전략 → 컬러 시스템 → 타이포그래피 → UI 컴포넌트 가이드북 확인

    ├── prompts.ts            # AI 프롬프트
    ├── types.ts              # 타입 정의
    ├── evaluator.ts          # 자동 평가 로직
    └── prompt-memory.ts      # 프롬프트 개선 메모리

## 가이드북 구성

- **브랜드 전략** — 브랜드 에센스, 핵심 가치, 톤앤매너, 디자인 방향성
- **컬러 시스템** — Primary / Secondary / Accent / Neutral / Semantic 컬러
- **타이포그래피** — 폰트 패밀리, 타입 스케일, 프리뷰
- **여백 & 그리드** — 스페이싱 스케일, Border Radius
- **UI 컴포넌트** — Button, Input, Checkbox, Radio, Badge, Tag, Accordion, Breadcrumb, Card

---

## 완료 조건

> 브랜드 키워드 1개 이상 입력 후 디자인 가이드북(컬러 시스템·타이포그래피·UI 컴포넌트)이 **30초 이내**에 생성된다.
